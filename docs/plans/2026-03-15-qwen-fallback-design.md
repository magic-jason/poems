# DashScope 解析 qwen3-max 兜底设计

## 背景

当前万象模式在诗词解析阶段固定使用 `qwen-plus`。当该模型临时不可用、服务受限或账号额度不足时，整条万象链路会直接失败，即便同一账号下 `qwen3-max` 仍可用。

## 目标

在不改动前端交互的前提下，为桌面端 DashScope 诗词解析增加一个后端自动兜底：

- 首选 `qwen-plus`
- 当且仅当识别为“模型不可用”或“额度不足/限流”场景时，自动降级到 `qwen3-max`
- 若两者都失败，向前端返回包含主模型与兜底模型信息的明确错误

## 方案

采用 Rust 后端串行兜底：

1. 将 DashScope 解析 payload 构造函数改为接受显式模型名
2. 新增错误分类 helper，只在可兜底错误上切换到 `qwen3-max`
3. 保留现有 JSON schema 输出要求，确保两种模型返回结构一致
4. 增加单元测试覆盖：
   - `qwen-plus` payload 构造
   - `qwen3-max` payload 构造
   - 不可用/额度错误触发 fallback
   - 普通参数错误不触发 fallback

## 不做

- 不修改前端模型选项
- 不新增设置项
- 不改变万相出图模型
